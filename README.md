# MIT 金融课精华蒸馏 · 交互式知识图谱

一堂 85 分钟 MIT 硬核金融公开课《把投资从赌博变成科学》的蒸馏可视化页面：**中心思想 + 七大认知模块流程 + 交互实验室 + 延伸学习**，纯静态、零依赖、单页应用。

## 在线预览

无需构建，任选一种方式启动本地服务：

```bash
# Python
python -m http.server 8899

# 或 Node
npx serve .
```

然后访问 <http://localhost:8899>

## 目录结构

```
MIT-Finance/
├── index.html            # 页面骨架（结构 + 区块容器）
├── css/
│   └── style.css         # 全部样式（深色主题、组件、响应式）
├── js/
│   ├── data.js           # 数据层：七大模块 / 延伸学习资源 / 测验 / 行动清单
│   ├── diagrams.js       # 图解层：全部 SVG 图解生成器（模块 + 资源）
│   ├── roadmap.js        # 路线图节点渲染 + 延伸学习卡片 + 通用详情弹窗
│   ├── lab.js            # 交互实验室：复利引擎 + 凯利公式计算器
│   ├── quiz.js           # 认知自检测验 + 行动清单
│   └── main.js           # 主入口：通用交互、雪球动画、滚动显现、导航高亮
└── README.md
```

脚本按依赖顺序加载：`data.js → diagrams.js → roadmap.js → lab.js → quiz.js → main.js`。

## 页面构成

| 区块 | 交互 |
| --- | --- |
| Hero · 中心思想 | 雪球滚山坡动画；三根支柱卡片点击展开 |
| 赌博 vs 科学 | 双栏对比，点击任意行高亮 |
| 七大模块流程 | SVG 路线图 7 个节点全部可点击，弹窗含图解/公式/行动建议，探索进度点亮 |
| 交互实验室 | 复利引擎（5 滑块实时重绘曲线）+ 凯利公式计算器（实时求解最优仓位） |
| 认知自检 | 3 道题即时判定 + 解析 |
| 行动清单 | 6 项可勾选，进度实时统计 |
| 延伸学习 | 4 张资源卡片，点击查看图解与入门建议 |
